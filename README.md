# marketplace-tributario

**Catálogo derivado. No se edita aquí.**

Lo genera `catalogos.py` desde el campo `catalogos:` de cada `saber.yaml`. Cualquier cambio hecho
a mano lo pisa la siguiente sincronización.

La única cosa que **no** se deriva es el `ref` de cada plugin: eso es el pin, y moverlo es
promover — una decisión aparte de publicar.
